# Vendor A

Vendor A API sederhana menggunakan Express JS yang menampilkan data produk dari warung. Semua data bertipe data String karena mensimulasikan sistem lama.

## Teknologi yag digunakan
1. Node.js
2. Express.js
3. CORS

## Data Produk
Data disimpan dalam bentuk array objek seperti:
1. kd_produk
2. nm_brg
3. hrg
4. ket_stok

## Endpoint API
1. GET (/) untuk menampilkan halaman utama dimana pada kode terdapat pesan sambutan.
2. GET (/daftarWarung) untuk menampilkan daftar produk warung.
